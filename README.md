### 🏭 What I work on

- **AVEVA System Platform** — object-oriented templates, instance hierarchies, ArchestrA scripting, redundant AppEngines
- **AVEVA OMI** — operator interfaces, city dashboards, navigation layouts and alarm displays
- **AVEVA Historian** — server &amp; client configuration, storage, deadband, trends and alarm management
- **Multi-protocol integration** — OPC UA, OPC DA, Modbus TCP, MQTT, BACnet: electrical, UPS, fire alarm, CCTV, water, wastewater and irrigation systems
- **Infrastructure** — redundant application servers, Hyper-V virtualization, Windows Server, AVEVA licensing
- **Site testing &amp; commissioning** and **technical documentation** — operator guides, production &amp; maintenance manuals
